# Jorge Remodelaciones & Acabados

Landing page de alta conversión para servicios residenciales de remodelación y terminación de apartamentos en obra gris en el Oriente Antioqueño y Valle de Aburrá.

## ✨ Características Principales

- **Diseño Moderno & Dark Luxury:** Paleta cuidada en tonos grafito/obsidiana y acentos dorados champagne.
- **Fondo de Partículas Espaciales:** Canvas interactivo acelerado por GPU que reacciona con física suave al movimiento del cursor.
- **Sliders de Antes & Después:** Comparadores táctiles e interactivos para evidenciar la transformación desde obra gris hasta terminados de lujo.
- **Galería Dinámica con Filtros y Lightbox:** Catálogo clasificado por categorías (*Cocinas*, *Baños*, *Sociales & Clósets*) con visualizador en pantalla completa.
- **Hub de Conversión Directa a WhatsApp:** Conexión directa y sin fricción con la asesora comercial **Alejandra Arbeláez** (`+57 310 801 1600`) con mensajes pre-redactados y chips de acciones rápidas.
- **Optimización & Rendimiento:** Cero dependencias pesadas, HTML5 semántico, CSS modular y JavaScript vanilla.

## 🛠️ Tecnologías

- HTML5 Semántico + Schema.org `LocalBusiness`
- CSS3 Moderno (CSS Variables, Flexbox, Grid, Glassmorphism)
- JavaScript Vanilla modular
- Google Fonts (`Google Sans Flex`, `Google Sans Code`, `DM Serif Display`, `Inter`)
